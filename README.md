## 🚀 Proyecto destacado

### [💪 LevelUp — Plataforma fitness web y móvil](https://github.com/guillegomezlopez3/FinalTFG)

Plataforma completa para entrenadores personales y clientes, desarrollada como Trabajo Fin de Grado del ciclo DAM. Incluye backend REST, panel web para entrenadores y aplicación móvil para clientes.

**Lo que incluye:**
- 🔐 Autenticación y autorización con **JWT + Spring Security**, control de acceso por roles (entrenador / cliente / admin)
- 👥 Gestión de usuarios, entrenadores y clientes con relaciones entre entidades
- 🏋️ Módulo de **rutinas de entrenamiento** — creación, asignación y seguimiento por cliente
- 🥗 Módulo de **dietas** — planes personalizados asignados por el entrenador
- 📈 **Seguimiento de progreso físico** — registro de métricas a lo largo del tiempo
- 💬 **Chat interno** entre entrenador y cliente
- 💳 **Pagos y suscripciones** con Stripe — sesiones de checkout y webhooks
- 🌐 **Panel web** con Thymeleaf + Bootstrap para entrenadores
- 📱 **Aplicación móvil Flutter** conectada al backend mediante HTTP
- ☁️ **Despliegue en cloud**: backend en Render, base de datos MySQL en Aiven

**Arquitectura:**
```
Controllers (REST) → Services → Repositories → Entities / DTOs → MySQL
```

`Java 21` `Spring Boot` `Spring Security` `JWT` `JPA/Hibernate` `MySQL` `Flutter` `Thymeleaf` `Bootstrap` `Stripe` `Render` `Aiven` `Git`
